# TablePilot

A Windows and Linux database workbench derived from DBX, with AI and MCP runtime features removed.

The first Actions run imports the checksum-verified TablePilot 0.3.0 source and builds Windows `.exe` and Linux `.deb` installers. The full project README replaces this bootstrap note after the import.

See [installer builds](https://github.com/deckeeper/TablePilot/actions).
