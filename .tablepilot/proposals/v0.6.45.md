# Reviewed DBX v0.6.45 update for TablePilot 0.3.2

Reviewed on 16 October 2026. Upstream commit: `13b6acafed41e1ce65d5e97344e7e93cb88202c2` (previous baseline: `0db01f7f284ec6b0b090fe7369de7d05c37b25b0`).

## Included

- Grid filtering, transforms, pagination and result-view fixes.
- Oracle constraints, indexes, foreign keys, security details and object rename previews; OceanBase and StarRocks schema improvements.
- Default saved-query/autosave storage and native commands, Save All Tabs, settings close handling, SQL-file preview/retry fixes, Redis value-preview options, and combined sidebar comments/sizes.
- Thai translations and other non-AI localization corrections.
- Normal database-driver metadata and plugin process cleanup, with matching frontend/backend support and regression tests.

## Excluded or retained

- No new AI conversations, assistant-mode/action storage, AI provider/CodeBuddy updates, AI settings/descriptions, AI SQL execution feedback or AI translations.
- Removed the MCP-only plugin discovery helper and its tests while retaining general plugin lifecycle fixes.
- Retained TablePilot native/API/plugin AI blocks, branding, removed GitHub GUI navigation, disabled upstream app updater, and independent Windows/Linux release workflows.
- Retained existing frontend/tooling dependencies and lockfiles. Upstream Windows 7 release-workflow tests do not apply to TablePilot's Windows 11/Linux packaging and were not updated or included in this validation.
- Passive legacy AI storage types/strings already present in TablePilot remain for compatibility; they do not expose executable AI/MCP functionality.

## Validation

Frontend build and full type check passed. Consolidated tests: 5,396 passed, 69 AI/MCP tests skipped, no unresolved failures. See `VALIDATION.md` for measured checks and remaining native/interactive validation. Windows/Linux native builds and installer publication are handled by TablePilot CI after merge.
