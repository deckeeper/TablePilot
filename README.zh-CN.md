# TablePilot

<!-- TablePilot modification: repository-specific documentation, 16 October 2026. -->

适用于 Windows 和 Linux 的桌面数据库工作台，支持 SQL 编辑、表格浏览与编辑、CSV/Excel 导入导出、字段映射、SSH 隧道和明暗主题。

- [下载安装包](https://github.com/deckeeper/TablePilot/releases)
- [完整使用和构建说明](README.md)
- [贡献指南](CONTRIBUTING.zh-CN.md)
- [安全问题报告](SECURITY.md)

桌面版不包含 AI、MCP 或插件中心；数据库驱动管理器仍然可用。应用会检查本仓库的正式版本，并打开下载页面供手动更新。
